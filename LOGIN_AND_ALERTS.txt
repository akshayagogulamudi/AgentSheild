TO ENABLE REAL EMAIL ALERTS (Optional):
================================================================================

Step 1: Get Gmail App Password
   - Go to: https://myaccount.google.com/
   - Click "Security"
   - Scroll to "App passwords"
   - Select "Mail" and "Windows Computer"
   - Google gives you 16-character password
   - Copy it

Step 2: Edit backend/.env file
   Replace this:
     NOTIFICATION_MODE=mock
     SMTP_USERNAME=your_email@gmail.com
     SMTP_PASSWORD=your_app_password
     ALERT_EMAIL_TO=security@company.com

   With your actual values:
     NOTIFICATION_MODE=live
     SMTP_USERNAME=your_actual_email@gmail.com
     SMTP_PASSWORD=xxxx xxxx xxxx xxxx
     ALERT_EMAIL_TO=your_actual_email@gmail.com

Step 3: Restart backend
   - Stop the backend process (Ctrl+C)
   - Run again:
     $env:PYTHONIOENCODING="utf-8"
     python -m uvicorn main:app --reload --port 8000

Step 4: Test
   - Go to Attack Simulation Lab
   - Trigger a threat
   - Check your Gmail inbox in ~2 seconds
   - Real email arrives!

TO ENABLE REAL SMS ALERTS (Optional):
================================================================================

Step 1: Create Twilio Account
   - Go to: https://www.twilio.com/try-twilio
   - Sign up (free, $15 credit)
   - Verify your phone number

Step 2: Get Twilio Credentials
   - Go to: https://console.twilio.com
   - Find "Account SID" (under your name at top)
   - Find "Auth Token" (click to show)
   - Go to "Phone Numbers" → Copy your Twilio number

Step 3: Edit backend/.env file
   Add/replace:
     TWILIO_ACCOUNT_SID=ACxxxxxxxxxx
     TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxx
     TWILIO_PHONE_NUMBER=+1234567890
     ALERT_PHONE_TO=+1234567890

Step 4: Verify recipient phone numbers (First time only)
   - In Twilio console, go to "Verify"
   - Send verification code to your phone
   - Enter code to verify
   - Now SMS will work

Step 5: Restart backend
   - Stop backend (Ctrl+C)
   - Run again:
     $env:PYTHONIOENCODING="utf-8"
     python -m uvicorn main:app --reload --port 8000

Step 6: Test
   - Go to Attack Simulation Lab
   - Trigger a threat
   - Check your phone in ~2 seconds
   - Real SMS arrives!

MOCK MODE vs LIVE MODE:
================================================================================

MOCK MODE (Current - Safe):
   - NOTIFICATION_MODE=mock
   - No real emails sent
   - No real SMS sent
   - Logs show: "[MAIL] Email would be sent..."
   - Perfect for testing and demos

LIVE MODE (Real Alerts):
   - NOTIFICATION_MODE=live
   - Real emails via Gmail SMTP
   - Real SMS via Twilio
   - Requires credentials
   - Ready for production

Current: MOCK MODE ✓
